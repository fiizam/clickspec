// 1. Imports standard Playwright runner
import { test, expect } from '@playwright/test';

test('User completes authentication flow', async ({ page }) => {
// Initial target page navigation
await page.goto('https://app.example.com/login');

// Semantic locators (no fragile div > div selectors)
await page.getByLabel('Email address').fill('alex@company.com');
await page.getByLabel('Password').fill('••••••••••••');
await page.getByRole('button', { name: 'Sign in' }).click();

// Smart assertions inferred automatically from DOM mutations
await expect(page).toHaveURL(/.*dashboard/);
await expect(page.getByRole('heading', { name: 'Overview' })).toBeVisible();
await expect(page.getByRole('status')).toContainText('Welcome back');
});

The problem with basic recorders

Tools like playwright codegen capture raw clicks, but their output usually creates brittle tests that fail on minor CSS updates.

Standard Codegen Output
  • • Produces fragile CSS paths like div > div:nth-child(3) > button.
  • • Generates zero assertions. It records clicks, but never checks if an alert or toast appeared.
  • • Produces noisy, non-atomic events when users type quickly.
// Fragile: breaks on minor UI refactor
clickspec Output
  • • Prioritizes accessible roles (getByRole, getByLabel, getByTestId).
  • • Watches DOM mutations and injects smart expect(...) assertions automatically.
  • • Debounces keystrokes into single atomic fill() commands.
// Resilient: survives layout updates

Built for production test suites

Four foundational pillars that make the synthesized code clean, stable, and ready to check in to Git.

Semantic Locators

Prioritizes user-facing accessibility semantics. Strict zero-CSS-path rule ensures selectors do not break when styles change.

Smart Assertion Hook

Captures DOM mutation signals after every significant user action, automatically asserting toast visibility, dialog openings, and redirects.

Event Normalization

Eliminates rapid typing noise and accidental double-clicks before passing session context to the model, reducing token costs by over 70%.

Dual Model Backend

Native support for Google Gemini 3.8 Flash via @google/genai, with seamless fallback to OpenAI, Groq, or local Ollama instances.
